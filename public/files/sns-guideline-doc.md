## 9. コンテンツ作成ガイドライン

### 9.1 参考資料の活用原則
- **メインメッセージは参考資料から抽出**
- 専門用語や独自の考え方をそのまま活用
- 数字や統計データを優先的に使用
- 参考資料の論理展開を尊重

### 9.2 事例変換の方法

**A. 他社コンテンツ（YouTube等）の場合**

**変換必須項目：**
- 具体的な数字（630個など）→別の数字に
- 比喩・例え話（医者の例など）→別の例えに  
- 具体的なエピソード→オリジナルエピソードに
- 業界特有の事例→汎用的な事例に

```
変換例：
参考：コールセンターの電話対応
→ 請求書処理プロセス
→ 日報作成プロセス
→ 在庫確認プロセス
（多くの企業が共感できる内容に）
```

**活用して良いもの：**
- 考え方の流れ（3ステップなど）
- 問題提起の構造
- 「なぜ」を問う手法
- 業務改善の順番の考え方

**B. 自社コンテンツ（弊社事例）の場合**
- 数字、エピソード、具体例はそのまま使用OK
- クライアント許可があれば業界名も使用可
- 代表の体験談（GU、リクルート）もそのまま使用可

### 9.3 差別化のための工夫
- 同じナレッジフレーズの連続使用を避ける
- 「4つの時間不足」「泥臭い」「伴走支援」は月1-2回程度
- 参考資料の異なる部分を毎回フォーカス
- 弊社要素は最後のCTA部分に集約

### 9.4 投稿作成時の注意
- 参考資料の内容：80%
- 弊社ナレッジ：20%（主にCTA部分）
- 具体的な企業名・業界名は出さない
- 数字は具体的に（参考資料から引用）

## 1. 発信コンセプト

### メインコンセプト
**「地方のデジタル化を加速させる伴走パートナー」**

埼玉県の商工会議所や地域企業のデジタル化支援の環境を活かし、デジタル化の「過程」を見せることで信頼を構築。プロセスエコノミーを実現する独自の発信戦略。

### 戦略的差別化ポイント
**「デジタル化の過程を見せられるのは、うちだけ」**
- 実際の支援現場に入り込んでいるからこそ可能
- 成功だけでなく試行錯誤も含めて公開
- 他社には真似できない透明性の高い発信

### ビジネスモデルの特徴
**「派手さはないが、堅実で持続可能」**
- 基礎的な支援（手書き→デジタル）でも劇的な成果
- 地方創生への貢献により社会的価値を創出
- 企業のSDGs達成にも貢献（デジタル格差解消）
- 一発の大きな開発より、確実な積み重ね

## 2. ターゲット

### メインターゲット
**中小企業経営者・後継者（従業員15～50名）**

**重点業種**
1. 建設業（行政書類に追われている）
2. 製造業（在庫管理・生産管理で苦労）
3. 福祉・医療（人手不足と事務作業の板挟み）
4. 飲食業（システムコストに悩む）
5. 小売業（在庫と顧客管理が煩雑）

**共通の悩み**
- 何から手をつければ良いか分からない
- 日々の業務に追われ「考える時間すらない」
- 高額なシステム導入には抵抗がある
- 身近な成功事例があれば試してみたい

- 内容：具体的な支援事例を10-15分で解説
- 頻度：月2本（一気撮り）

**AI/DX解説動画（松岡）**
- 内容：AI活用、DXの体系的解説
- 頻度：週2本（水・土）


## 6. 制作フロー

### 競合コンテンツ活用の優先順位
**参考資料8割：ナレッジ2割の原則**
1. **参考資料（YouTube等）の内容を80%活用**
   - 文字起こし内容の核心メッセージを抽出
   - 具体的な数字、手法、考え方を活用
   - 専門用語や独自の視点をそのまま活かす
2. **ナレッジは20%程度の補足**
   - 弊社の価値観を軽く織り込む程度
   - 毎回同じフレーズは使わない
   - 月1回程度に特徴的な表現を制限
3. **事例の変換ルール**
   - 参考資料と同じ事例は使用禁止
   - 中小企業全般に共通する課題に変換
   - 業界を限定せず幅広い企業が共感できる内容に

### 支援事例活用
1. 事例一覧から素材選定
2. クライアント許可確認
3. 数字や成果を明確化
4. 各媒体向けにコンテンツ化

## 7. 運用ルール

### 必須事項
- ✅ 数字は具体的に（％、時間、金額）
- ✅ 改行を多用して読みやすく
- ✅ IT導入補助金の活用事例を積極的に紹介
- ✅ 地域は「埼玉県」レベルまで（行田市は非公表）

### NG事項
- ❌ 行田市の名前を出す
- ❌ クライアント企業名の無断公開
- ❌ 「誰でも簡単に」という誇大表現
- ❌ 他社サービスの批判
- ❌ 補助金を否定するような表現

### CTA（行動喚起）
**段階的に使い分け**
- 軽：「フォローで続きをチェック」
- 中：「詳しい事例集をLINEで配信」
- 強：「無料相談（30分）でお話しませんか」

## 8. 弊社の強みと差別化（コンテンツ作成用データ）

### ビジョン・ミッション
**VISION**: 地方・中小企業に、IT人材がいなくても進化できる仕組みを
**MISSION**: デジタルを"もっと身近"に

### 基本理念
「人がやるべきこととやらなくても良いことの線引きを極限まで明確にして形にする」
- これが効率化の本質であり、弊社のすべてのサービスの根幹
- AIは効率化ツールであって、魔法のツールではない

### 他社との違い
**他社のAI支援の問題点**
- AIの使い方だけ教えて終わり
- 単発の研修で継続サポートなし
- オンラインのみで現場の実情を理解していない
- 汎用的な内容で自社に合わない
- 導入後に定着しない

**実態データ**
- AI導入企業の70%が「期待した効果が得られていない」
- 中小企業の85%が「デジタル化に取り組みたいが方法が分からない」
- 導入後の定着率はわずか30%
→ 本当の問題は「導入」ではなく「定着」

### 中小企業経営者の現実的な課題

**表面的な悩み**
- AIで何ができるのか具体的に分からない
- 現場が忙しすぎて調べる余裕がない
- 情報が溢れていて何が正しいか判断できない
- 手書きやExcel手入力作業に追われている
- データが煩雑で整理に時間を取られている
- 時代に取り残される不安がある

**本質的な課題：4つの時間不足の連鎖**
1. 考える時間がない
2. 調べる時間もない
3. 選ぶ時間もない
4. 使う時間もない
→ どこかで挫折してしまい、デジタル化できない

**現場の現実**
- 現場も忙しくて任せられない
- IT知識や業務を俯瞰した経験がない
- 新しいことを覚えるのに疲弊する

**採用の困難さ**
- 社員を雇うのはリスクが高い
- IT詳しい人は稀で採用できない
- 採用できない間に現場は疲弊し悪循環

### 事業継承・企業存続への影響

デジタル化支援は事業継承や企業の存続に関わる大きな改革：
- ベテランの手書き文化に若手が不安を感じ早期退職
- 新世代への引き継ぎが困難
- そのまま会社が終わる悲しい結末も

→ この悲しい結末を伴走支援で解消してきた

### AI活用の現実と弊社の立ち位置

**AI活用の本当の難しさ**
AI活用には以下の全てが必要：
- あるべき状態の明確な理解
- 必要な要素の把握と言語化能力
- 適切な情報収集と環境整備
- 実行ステップの設計（量・質・手順）
- ITと現場の両方を理解し橋渡しする人材

→ これらが揃わないと、ツール導入も研修も頓挫する

**ほとんどの企業が経験する失敗サイクル**
1. AIツール導入や研修を実施
2. 社内に浸透できず頓挫
3. 元の作業方法に戻る
4. 「やっぱりうちには無理」という諦め

これから増加するAIサービス業者により、この挫折体験はさらに増える見込み。

**弊社の価値観：泥臭さこそが信頼**
- スマートに見せようとする他社が多い中、あえて泥臭く
- 現場の課題と正面から向き合う姿勢を見せる
- 失敗も含めて共有することで「うちも同じ」という共感
- IT×現場の橋渡し役として伴走

→ この泥臭い姿勢こそが、中小企業からの信頼獲得の源泉

### 弊社の解決アプローチ

**伴走支援の特徴**
- 現場に入り込んで一緒に考える
- 段階的に「階段を一段ずつ」進める
- 定着するまで寄り添い続ける
- 企業様1社ずつに合ったオーダーメイド支援

**支援内容の実態**
- Excel自動化、業務整理など基礎的な内容でも劇的な成果
- 「何ができるかわからない」レベルの企業に最大の価値を提供
- 手書きからデジタルへの移行だけで80%削減などの成果

**スケーラビリティ戦略**
1. 業界別に5社程度支援すると共通課題が見える
2. 業界別担当制で知見を蓄積
3. 共通課題を自社ツール化して横展開
→ 労働集約型から脱却する道筋

**社会的価値**
- 地方創生への貢献（地域企業の競争力向上）
- SDGsへの貢献（デジタル格差の解消）
- 事業継承問題の解決（若手が働きたくなる職場へ）

**支援実績**
- 200社以上の中小企業支援
- 継続率85%以上
- 平均継続期間12ヶ月
