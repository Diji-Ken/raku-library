## 1. ヘッダー

**位置**: 画面上部、常に表示（見開きビュー時のみ非表示）

### アクションボタン（左から右へ）

1. **ファイルを追加ボタン**
   - 色: 紫（#667eea）
   - アイコン: Plus
   - 機能: ファイル追加モーダルを開く
   - ホバー時: 色が#764ba2に変化

2. **フォルダ作成ボタン**
   - 色: 白地に紫枠
   - アイコン: FolderPlus
   - 機能: 新規フォルダ作成モーダルを開く

3. **親フォルダ作成ボタン**
   - 色: 白地に紫枠（#8b5cf6）
   - アイコン: Book
   - 機能: 新規キャビネット（親フォルダ）作成モーダルを開く

4. **エクスポートボタン**
   - 色: 白地にグレー枠
   - アイコン: Download
   - 機能: ライブラリ全体をJSONファイルとしてエクスポート

5. **ソート選択ドロップダウン**
   - オプション:
     - 名前順 (A → Z)
     - 名前順 (Z → A)
     - 日付順 (古い順)
     - 日付順 (新しい順)
   - 機能: 表示されるアイテムの並び順を変更

## 2. サイドバー

**位置**: 画面左側、300px幅
**開閉**: トグルボタンで開閉可能

### サイドバー内の要素

1. **トグルボタン（サイドバー閉じる）**
   - 位置: 右上
   - アイコン: ChevronLeft
   - 機能: サイドバーを閉じる

2. **フォルダ検索**
   - プレースホルダー: "フォルダを検索..."
   - アイコン: Search
   - 機能: フォルダ名でフィルタリング

3. **ドキュメント検索**
   - プレースホルダー: "ドキュメントを検索..."
   - アイコン: Search
   - 機能: ドキュメント名でフィルタリング

4. **ツリー構造表示**
   - キャビネット → フォルダ → サブフォルダの階層表示
   - 各アイテムの機能:
     - **キャビネット**:
       - 展開/折りたたみ: ChevronDownアイコン
       - **編集ボタン** (新規追加): 名前をインライン編集
       - アイコン: Book
     - **フォルダ**:
       - 展開/折りたたみ: ChevronDownアイコン（子要素がある場合）
       - クリック: 本棚ビューに切り替え
       - **編集ボタン** (新規追加): 名前をインライン編集
       - **削除ボタン**: 削除確認モーダルを表示
       - アイコン: Folder / FolderOpen

### サイドバーが閉じている時

- **開くボタン**
  - 位置: 左端に固定
  - アイコン: ChevronRight
  - 機能: サイドバーを開く

## 3. メインコンテンツエリア

### 3.1 初期状態（何も選択していない時）

- **ドラッグ&ドロップゾーン**
  - 説明テキスト: "ここにファイルをドロップ"
  - "または左のサイドバーからフォルダを選択すると、本棚が表示されます"
  - ファイルドラッグ中: 背景色が紫に変化

### 3.2 フォルダ選択時 - 本棚ビュー（BookshelfView）

**表示内容**:
- フォルダ名がヘッダーに表示
- フォルダ内のドキュメントを本の背表紙風に表示
- 1行あたり最大20冊

**BookCard（本のカード）の情報**:
- ドキュメント名（縦書き）
- ページ数（例: "5p"）
- ラベルカラー（blue/green/red/yellow/purple）

**戻るボタン**:
- 位置: 左上
- アイコン: ChevronLeft
- 機能: フォルダ選択を解除、初期画面に戻る

### 3.3 キャビネット選択時（FolderListView）

**表示内容**:
- キャビネット内のフォルダをカード形式で表示
- 各フォルダカードに:
  - フォルダ名（縦書き）
  - 中のドキュメント数

## 4. ドキュメントビューワー

### 4.1 見開きビュー（Spread View）

**ツールバー**（上部）:
1. **本棚に戻るボタン**
   - アイコン: ChevronLeft
   - 機能: ドキュメントを閉じて本棚に戻る

2. **ズームアウトボタン**
3. **ズーム率表示**（例: "100%"）
4. **ズームインボタン**
5. **回転ボタン**
   - 機能: ページを90度回転

**ドキュメント表示エリア**:
- 見開き2ページ表示
- ページめくりアニメーション
- ドラッグでページめくり（左右スワイプ）

**フッター**（下部）:
- **現在のページ番号 / 総ページ数**
  - 例: "1 / 10"
  - スタイル: 白い背景、影付き

- **メタデータ編集ボタン** (新規追加)
  - 位置: 右から204px
  - アイコン: Edit3
  - 機能: ドキュメントのメタデータ編集モーダルを開く

- **印刷ボタン**
  - 位置: 右から144px
  - アイコン: Printer
  - 機能: 現在表示中のページを印刷

- **ダウンロードボタン**
  - 位置: 右から84px
  - アイコン: Download
  - 機能: 元のファイルをダウンロード

- **閉じるボタン**
  - 位置: 右から24px
  - アイコン: X
  - 機能: ビューワーを閉じる

### 4.2 ナビゲーション

**キーボードショートカット**:
- 左矢印キー: 前のページへ
- 右矢印キー: 次のページへ
- Escキー: ビューワーを閉じる

**マウス操作**:
- ドラッグ（スワイプ）: ページめくり

## 5. モーダル

### 5.1 削除確認モーダル

**トリガー**: フォルダ/ドキュメントの削除ボタンをクリック

**表示内容**:
- ヘッダー: 赤いグラデーション背景
- アイコン: Trash2
- タイトル: "フォルダを削除" または "ドキュメントを削除"
- 警告メッセージ: 削除対象の名前と「この操作は取り消せません」

**アクションボタン**:
- キャンセルボタン（グレー）
- 削除するボタン（赤）

### 5.2 メタデータ編集モーダル (新規追加)

**トリガー**: ドキュメントビューワーのメタデータ編集ボタンをクリック

**表示内容**:
- ヘッダー: 紫グラデーション背景
- アイコン: Edit3
- タイトル: "ドキュメント情報を編集"

**編集フィールド**:
1. **ドキュメント名**
   - テキスト入力フィールド
   - プレースホルダー: "ドキュメント名を入力"

2. **ラベルカラー**
   - 5色のボタン選択
   - 色オプション: ブルー、グリーン、レッド、イエロー、パープル
   - 選択中の色にはチェックマーク表示

**アクションボタン**:
- キャンセルボタン（グレー）
- 保存ボタン（紫グラデーション）

### 5.3 新規フォルダ作成モーダル

**トリガー**: ヘッダーの「フォルダ作成」ボタンをクリック

**表示内容**:
- タイトル: "新しいフォルダを作成"
- フォルダ名入力フィールド
- 親フォルダ選択ドロップダウン

**アクションボタン**:
- キャンセル
- 作成

### 5.4 ファイル追加モーダル

**トリガー**: ヘッダーの「ファイルを追加」ボタンをクリック

**表示内容**:
- タイトル: "ファイルを追加"
- 3つの選択肢:
  1. **個別ファイルを選択**: ファイル選択ダイアログを開く
  2. **フォルダごとアップロード**: フォルダ選択ダイアログを開く
  3. **ドラッグ&ドロップで追加**: ドロップゾーンを表示

### 5.5 キャビネット作成モーダル

**トリガー**: ヘッダーの「親フォルダ作成」ボタンをクリック

**表示内容**:
- タイトル: "新しい親フォルダを作成"
- キャビネット名入力フィールド

**アクションボタン**:
- キャンセル
- 作成

## 6. その他の機能

### 6.1 ファイル対応形式

**画像**:
- PDF
- JPEG, JPG, PNG, HEIC, WebP, GIF, BMP

**動画**:
- MP4, MOV, AVI

**ドキュメント**:
- Word (.docx, .doc)
- Excel (.xlsx, .xls)
- CSV
- テキスト (.txt)
- Markdown (.md, .markdown)
- JSON
- HTML (.html, .htm)

### 6.2 ドラッグ&ドロップ

- メインコンテンツエリアへのファイルドロップ
- ドロップ時の視覚フィードバック（背景色変化、点線枠）

### 6.3 検索機能

- フォルダ名検索（サイドバー）
- ドキュメント名検索（サイドバー）
- リアルタイムフィルタリング

### 6.4 データ永続化

- LocalStorageへの自動保存
- JSONエクスポート/インポート機能

## 📝 問題点・改善が必要な箇所

### 1. **フォルダ/キャビネットの編集・削除ボタン**
❌ **問題**:
- ボタンが小さくて見えにくい
- 編集と削除の色が区別しづらい
- ホバーしないと存在がわからない
- インライン編集の操作性が悪い

### 2. **メタデータ編集モーダル**
❌ **問題**:
- ツールバーの小さいボタンから開く（発見しにくい）
- 頻繁に使う機能なのにアクセスが悪い

### 3. **検索機能**
❌ **問題**:
- フォルダ検索とドキュメント検索が別々
- 検索結果の表示が不明瞭

### 4. **ナビゲーション**
❌ **問題**:
- 階層が深いと戻りにくい
- パンくずリストがない
