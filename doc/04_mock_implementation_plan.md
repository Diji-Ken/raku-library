## 6. 技術的な実装メモ

### 6.1 見開き表示の実装
```tsx
const [viewMode, setViewMode] = useState<'single' | 'spread'>('single');

// 見開き表示時は2つのPageコンポーネントを並べる
{viewMode === 'spread' ? (
  <div className="spread-view">
    <Page pageNumber={currentPage} />
    <Page pageNumber={currentPage + 1} />
  </div>
) : (
  <Page pageNumber={currentPage} />
)}
```

### 6.2 ズーム機能の実装
```tsx
const [zoom, setZoom] = useState(100); // パーセント
const pdfScale = zoom / 100 * 1.2; // 基本スケールに倍率を掛ける

<Page scale={pdfScale} />
```

### 6.3 付箋機能の実装（簡易版）
```tsx
interface StickyNote {
  id: string;
  pageNumber: number;
  x: number;
  y: number;
  content: string;
  color: string;
}

const [stickyNotes, setStickyNotes] = useState<StickyNote[]>([]);

// LocalStorageに保存
useEffect(() => {
  localStorage.setItem('stickyNotes', JSON.stringify(stickyNotes));
}, [stickyNotes]);
```

## 7. デモ時の注意点

### 説明すべきポイント
1. **直感的な操作性**: マニュアル不要で使える
2. **楽々ライブラリとの互換性**: 既存の使い方を踏襲
3. **モダンなUI**: 見やすく、使いやすいデザイン
4. **拡張性**: 将来的な機能追加が容易

### 依頼者への確認事項
1. 必須機能は揃っているか
2. UI/UXは直感的か
3. 追加で欲しい機能はあるか
4. 既存データの移行に必要な情報は何か
